How to get a Gmail App Password

  1. Go to myaccount.google.com → Security
  2. Turn on 2-Step Verification (required)
  3. Open App passwords → create one named "Email Tool"
  4. Google shows a 16-letter code — paste it above as the password (both SMTP and IMAP)

Your normal Gmail password will NOT work — Google blocks it. The App Password is stored encrypted on this server only.

Outlook / Microsoft 365

SMTP: smtp.office365.com:587 (STARTTLS) · IMAP: outlook.office365.com:993 (SSL). Use an App Password if 2FA is on.
